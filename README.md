# Excel and VBA Repository

This repository contains custom Excel and VBA code solutions for managing calculations, queues, and other advanced functionalities.

## Directory Structure

- **src/Modules/**: Contains VBA modules for core functionality.
  - `ActiveTotals.bas`: Logic for running active totals.
  - `QueueHandler.bas`: Routines for managing queues.
  - `AdvancedMath.bas`: Handles advanced calculations.
- **tests/**: Test modules for verifying functionality.
  - `TestActiveTotals.bas`: Tests for ActiveTotals module.
  - `TestQueueHandler.bas`: Tests for QueueHandler module.
  - `TestAdvancedMath.bas`: Tests for AdvancedMath module.
